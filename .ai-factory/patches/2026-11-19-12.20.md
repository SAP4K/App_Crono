# Finish Android duration-wheel motion at the committed row

**Date:** 2026-11-19 12:20
**Files:** `modules/crono-duration-wheel/android/src/main/java/ro/appcrono/durationwheel/CronoDurationWheelModule.kt`, `tests/e2e/backup.spec.ts`
**Severity:** medium

## Problem

The first Android release of the acceleration profile sometimes kept Start and Apply disabled after the last visible movement. In a separate browser check, the literal legacy backup scenario intermittently threw while waiting for the first Save.

## Root Cause

The Android curve rounded offsets to physical pixels. Its last portion could have no pixels left to move while its nominal time was still running. The wheel waited for the time boundary even though it had already reached the exact target. The browser scenario assumed the raw stored legacy record already contained a `planning` field while its asynchronous write was pending.

## Solution

The Android wheel ends the coast on the first exact target pixel. It verifies the view committed that pixel and that the release still owns the motion before emitting the regular momentum-end event. The existing debug release trace records the target and elapsed time. The browser assertion retries until the raw stored schedule exists, then continues with the same reload and file transfer checks.

## Verification

On a Redmi Note 9 running Android 12, 540 × 1170 recordings measured 15 gestures on each screen. Timer stop-to-enabled median fell from 115.7 to 67.7 ms and max from 234.5 to 131.5 ms. Planning median fell from 186.5 to 86.1 ms and max from 219.5 to 122.0 ms. The same targeted browser selection passed all 18 scenarios after the backup assertion change. The Android release build and all six native unit tests passed.

## Prevention

Prove that native scrolling reached its target with the actual positioned view, then end the current writer as soon as its remaining offsets would be identical. Measure the final motion and the action separately. When polling legacy raw storage, let an absent field represent an incomplete write and assert the persisted value after the field becomes available.
