# Deliver the committed Android duration-wheel stop directly

**Date:** 2026-11-19 15:09  
**Files:** `modules/crono-duration-wheel/android/src/main/java/ro/appcrono/durationwheel/CronoDurationWheelModule.kt`  
**Severity:** low

## Problem

Planning occasionally took about 101 ms to show Apply enabled after the duration wheel had centered. Fourteen full-resolution recordings on an Android 12 Redmi Note 9 reproduced a median of 85.2 ms and a maximum of 101.2 ms.

## Root Cause

The custom coast committed the exact target and emitted a React Native momentum-end event immediately. Its `awaitStop` request returned `null`, so the event was the path that unlocked the UI. Across eight instrumented Planning gestures, delivery to JavaScript consistently cost 19.0–20.6 ms after the native stop. The React commit happened a median of 51.2 ms after the stop.

## Solution

Let the active coast register a stop observer through the existing timestamp-checked `awaitStop` path. Resolve it with the positioned offset and monotonic timestamp after the first exact target pixel. Retain the regular momentum-end event and resolve pending observers with `null` on cancellation. The `CronoWheelRelease` DEBUG tag records registration and resolution with the `[FIX:wheel-latency]` prefix.

## Verification

- All eight repeated diagnostics accepted the direct result. Median native stop to JavaScript delivery fell from 19.4 ms to 1.3 ms. Median native stop to React commit fell from 51.2 ms to 32.3 ms. The paired run medians for release to center were 1,209.0 ms and 1,208.5 ms.
- On the final signed APK, all 14 repeated Planning gestures committed the exact target. Full-resolution video measured a median of 48.4 ms and a p95 and maximum of 82.3 ms from the first sampled centered frame to Apply enabled. The installed APK matched SHA-256 `cfe4dc626c07630ea7bb99714a245630ed03cafb4552f4216ec02b13a5451e24`.
- Tap probes during braking left Timer idle and the Planning sheet open. The first eligible presses started `00:18:00` in Timer and applied `00:19:00` to the Planning draft. A ten-minute preset took over a current coast. Planning Cancel preserved the original five-minute draft. Native traces recorded a `null` observation for both cancelled coasts.
- Lint, typecheck, 327 Node tests, eight Android unit tests and clean Android release assembly passed.

## Prevention

Measure native centering, JavaScript receipt, React commit and the visible action state separately when investigating latency. Preserve gesture identity and exact-row validation on each completion path. Exercise an obsolete observer alongside valid stop delivery whenever a second native path can finish the same gesture.
